# Shellcamp

Learn ethical hacking from scratch, in your browser.

Shellcamp is a free practice site with 16 guided rooms in 5 learning paths:

1. **Start Here: Absolute Basics** – how computers work, binary and hex, ethics, protecting yourself
2. **Foundations** – Linux shell, permissions, networking, how the web works
3. **Crypto Basics** – encoding vs encryption, hashes and checksums
4. **Offensive Basics** – Nmap recon, finding hidden pages, SQL injection, XSS
5. **Defensive Basics** – defense in depth, investigating a break-in from logs

Every lab is simulated in the browser. Nothing touches a real network.
Progress is saved in your own browser only.

**Only test systems you own or have written permission to test.**

It is a single `index.html` file with no build step. Open it locally or host it on GitHub Pages.
