# Shellcamp

Learn ethical hacking from scratch, in your browser: **https://anayinjnani25.github.io/shellcamp/**

24 guided rooms in 7 learning paths:

1. **Start Here: Absolute Basics** – how computers work, binary and hex, ethics, protecting yourself
2. **Foundations** – Linux shell, permissions, Windows basics, networking, how the web works
3. **Crypto Basics** – encoding vs encryption, hashes and checksums
4. **Python for Hackers** – real Python in the browser: basics, loops, functions, scripts for defenders
5. **Offensive Basics** – Nmap recon, finding hidden pages, SQL injection, XSS, broken access control
6. **Defensive Basics** – defense in depth, investigating a break-in, phishing email analysis
7. **What Comes Next** – careers, certifications, legal practice

Every lab is simulated in the browser. Nothing touches a real network.
The Python editor uses [Pyodide](https://pyodide.org) to run Python locally in your browser.
Progress is saved in your own browser only.

**Only test systems you own or have written permission to test.**

It is a single `index.html` file with no build step.
